## Asset Classification Status:
- **[A] Authentic Hospital Assets:** Existing authentic procedural photos (e.g. `kizhi_hero.png`, `shirodhara_hero.png`).
- **[B] Approved Atmospheric Visuals:** High quality botanical / herbal / Kerala nature visuals used purely as background decorative textures. Must NEVER be captioned as actual hospital rooms or doctors.
- **[C] Pending Hospital Photography:** Real doctor headshots and facility photos to be supplied by hospital management.
